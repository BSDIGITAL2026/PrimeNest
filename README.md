📌 Project Overview

PrimeNest Realty is a modern real estate website concept designed to provide visitors with a clean and intuitive way to discover properties, filter listings, view property details, and contact a real estate team.

The project focuses on responsive design, user experience, interactive property searching, and functional contact communication.

✨ Features
	•	Responsive desktop and mobile design
	•	Modern real estate landing page
	•	Property search and filtering
	•	Location filtering
	•	Property type filtering
	•	Price range filtering
	•	Individual property details
	•	Schedule-a-viewing flow
	•	Responsive mobile navigation
	•	Contact form
	•	Email delivery through Formspree
	•	GitHub Pages deployment

🛠️ Technologies
	•	HTML5
	•	CSS3
	•	JavaScript
	•	Formspree
	•	GitHub Pages
